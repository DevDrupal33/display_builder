# Display Builder

A display building tool by the [UI Suite](https://www.drupal.org/project/ui_suite) team.

## Installation

Install as you would normally install a contributed Drupal module.
See: [Installing Modules](https://www.drupal.org/docs/extending-drupal/installing-modules) for further information.

!!!warning "Beta stage and Drupal 11.3+"
  The module is still in development and [some extra steps may be needed](./docs/install.md).
