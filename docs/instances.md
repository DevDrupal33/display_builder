# Instances overview

You need `display_builder_ui` sub-module.

Instances are volatile storage for your current work. They store the current drafts, the current revisions history, regardless of the published state of teh display.

They can be deleted without side-effects and are not expected to be synchronized between environment.

You can access to an overview of the current instances:

![Overview](images/instances.webp)

With a quick access to the corresponding display builder.
